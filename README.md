# Multi-Agent Equation Processing System

This repository contains a two-agent system for processing and analyzing mathematical equations. The first agent generates an equation based on a provided template, and the second agent determines the type of the equation (quadratic, linear, or cubic) using predefined rules.

---

## **Agents Overview**

### **Agent 1: `action_translate_equation`**
Generates an equation based on a template and performs argument mapping if needed.

#### **Parameters:**
- `equationTemplateAddr`: Contains a description of the equation template.
- *(Optional)* `argumentsSet`: A set of arguments for variables in the equation.

#### **Workflow:**
1. The agent replaces placeholders in the equation template with values from the argument set.
2. The generated equation is passed to **Agent 2** for type determination.

#### **Example Input:**
- **Template:** `a*x^2 + b*x + c = 0`
- **Arguments:** `{a: 2, b: 4, c: -6}`

#### **Example Output:**
- **Generated Equation:** `2*x^2 + 4*x - 6 = 0`

---

### **Agent 2: `action_define_equation_type`**
Determines the type of the equation generated by **Agent 1** based on predefined rules.

#### **Parameters:**
- `equationAddr`: Contains the equation generated by **Agent 1**.
- *(Optional)* `ruleSet`: A set of rules for determining the type of the equation.

#### **Workflow:**
1. Analyze the equation structure:
   - If it contains a term with `x^2` but no higher powers, classify as **quadratic**.
   - If it contains a term with `x` but no higher powers, classify as **linear**.
   - If it contains a term with `x^3`, classify as **cubic**.
2. Return the type of equation to the knowledge base.

#### **Example Input:**
- **Equation:** `2*x^2 + 4*x - 6 = 0`

#### **Example Output:**
- **Type:** `Quadratic`

---

## **Result Codes**
Both agents use the following result codes:

| Code                | Description                                   |
|---------------------|-----------------------------------------------|
| `SC_RESULT_OK`      | Action completed successfully.               |
| `SC_RESULT_ERROR`   | Internal error occurred during the action.   |

---

## **Example Workflow**

1. **Agent 1** receives the equation template `a*x^2 + b*x + c = 0` and arguments `{a: 2, b: 4, c: -6}`:
   - It generates the equation: `2*x^2 + 4*x - 6 = 0`.
   - The equation is passed to **Agent 2**.

2. **Agent 2** analyzes the equation `2*x^2 + 4*x - 6 = 0`:
   - Identifies the term `x^2` and no `x^3` terms.
   - Classifies the equation as **quadratic**.

3. **Final Result:**
   - **Generated Equation:** `2*x^2 + 4*x - 6 = 0`
   - **Equation Type:** `Quadratic`
